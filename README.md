# SystemTunerPro

### Очистка, управление файлами и системные настройки для Windows

---

> **Статус разработки**
> Проект активно развивается. Интерфейс, функции и формат настроек могут меняться.

SystemTunerPro помогает освободить место на диске, просмотреть найденные данные перед удалением, управлять внутренней корзиной и применять отдельные твики Windows с возможностью отмены.

## Что умеет

| Раздел | Возможности |
| --- | --- |
| Очистка | Поиск временных файлов Windows, кэшей браузеров и приложений, а также установленных программ через реестр |
| Контроль удаления | Размеры групп и файлов, выбор отдельных элементов, массовое выделение и безопасное удаление во внутреннюю корзину |
| Корзина | Восстановление файлов по исходному пути, защита от перезаписи и очистка внутренней или системной корзины |
| Файлы | Поиск больших файлов, просмотр директорий и перенос с сохранением структуры папок |
| Твики | Microsoft Defender, Windows Update и файл подкачки с сохранением исходных значений |
| Оформление | Светлая и тёмная темы, создание, импорт и экспорт пользовательских тем |

## Скачать

Актуальная версия доступна на странице [GitHub Releases](https://github.com/RilleSB/SystemTunerPro/releases/latest).

| Файл | Для кого | Что нужно |
| --- | --- | --- |
| `SystemTunerPro.exe` | Если на компьютере уже есть .NET 9 | [.NET 9 Desktop Runtime для Windows x64](https://dotnet.microsoft.com/download/dotnet/9.0) |
| `SystemTunerPro-…-portable.zip` | Если программа запускается на чистой Windows или нужна переносная версия | Ничего: распаковать архив и запустить `SystemTunerPro.exe` |

Оба варианта предназначены для Windows x64. Для твиков и части системных операций могут понадобиться права администратора.

## Безопасность и восстановление

- Перед удалением можно снять отметки с отдельных файлов или целых групп.
- При включённом безопасном удалении файлы переносятся во внутреннюю корзину, откуда их можно восстановить.
- При восстановлении программа не перезаписывает файл, если по исходному пути уже существует другой.
- Перед изменением Defender, Windows Update и файла подкачки сохраняется исходное состояние. В интерфейсе есть действие «Вернуть как было».

> Параметры Microsoft Defender могут игнорироваться Windows при включённом Tamper Protection.

## Сборка из исходников

Требуется Windows, [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) и доступ к NuGet.

```powershell
dotnet build -c Release
```

<details>
<summary>Создание релизных файлов</summary>

```powershell
.\scripts\publish-release.ps1 -Version 1.0.0
```

Скрипт формирует:

- `release\single-file\SystemTunerPro.exe` — небольшой framework-dependent EXE;
- `release\SystemTunerPro-1.0.0-win-x64-portable.zip` — автономный portable-архив.

Папка `release/` содержит локальные артефакты сборки и не добавляется в Git.

</details>

## Важное

Программа работает с файлами, реестром и службами Windows. Перед удалением проверяйте выбор. Системные изменения выполняются на ответственности пользователя; для поддерживаемых твиков приложение сохраняет значения для восстановления.
