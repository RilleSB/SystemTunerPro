# SystemTunerPro

SystemTunerPro — Windows-приложение для поиска временных файлов, очистки мусора, управления файлами и безопасной настройки отдельных параметров системы.

Проект написан на C# с использованием .NET 9 и Avalonia UI.

> Статус: проект находится в активной разработке. Возможны изменения интерфейса, функций и формата настроек.

## Возможности

### Очистка

- поиск временных файлов Windows;
- поиск кэшей браузеров и приложений;
- дополнительный поиск установленных приложений через реестр;
- просмотр найденных файлов по группам и подпапкам;
- отображение общего размера мусора и размера каждой группы;
- выбор отдельных файлов или всей группы перед удалением;
- безопасное удаление во внутреннюю корзину;
- окончательное удаление только при отключённом безопасном режиме.

### Внутренняя корзина и файлы

- восстановление файлов на прежнее место без перезаписи существующих файлов;
- очистка внутренней и системной корзины Windows;
- поиск больших файлов;
- перенос файлов с сохранением структуры папок;
- проверка путей перед операциями с файлами.

### Твики Windows

- управление Microsoft Defender;
- управление службой Windows Update;
- настройка файла подкачки;
- сохранение исходных значений перед изменением;
- восстановление каждого параметра в состояние «как было»;
- проверка прав администратора и результата системных команд.

Твики требуют запуска от имени администратора. На работу параметров Defender может влиять Tamper Protection Windows.

### Темы и настройки

- встроенные светлая и тёмная темы;
- создание, импорт и экспорт пользовательских тем;
- сохранение настроек приложения и языка интерфейса.

## Скачать

Файлы находятся в [GitHub Release v1.0.0](https://github.com/RilleSB/SystemTunerPro/releases/tag/v1.0.0).

### SystemTunerPro.exe

Небольшой одиночный EXE. Требует установленный [.NET 9 Desktop Runtime для Windows x64](https://dotnet.microsoft.com/download/dotnet/9.0). SDK для запуска не нужен.

### Portable ZIP

Архив со всеми необходимыми файлами приложения. Не требует отдельной установки .NET и подходит для запуска на чистой Windows x64. После распаковки запускайте `SystemTunerPro.exe`.

Для системных твиков могут потребоваться права администратора.

## Сборка из исходников

Требования:

- Windows;
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0);
- доступ к восстановлению NuGet-пакетов.

Обычная Release-сборка:

```powershell
dotnet build -c Release
```

Создание двух релизных вариантов:

```powershell
.\scripts\publish-release.ps1 -Version 1.0.0
```

Скрипт создаёт:

- `release\single-file\SystemTunerPro.exe` — framework-dependent EXE;
- `release\SystemTunerPro-1.0.0-win-x64-portable.zip` — self-contained portable-архив.

Папка `release/` содержит локальные артефакты сборки и не добавляется в Git.

## Структура проекта

- `Views/` — окна и разметка интерфейса Avalonia;
- `ViewModels/` — логика экранов и команд пользователя;
- `Services/` — поиск, очистка, корзина, темы, системные операции и настройки;
- `Models/` — модели файлов, тем и конфигурации;
- `Styles/` и `Assets/` — оформление и ресурсы приложения.

## Важные ограничения

Программа работает с системными файлами, реестром и службами Windows. Перед очисткой проверяйте выбранные группы и используйте безопасное удаление, если не уверены в результате. Изменения системных параметров выполняются на ответственности пользователя; для них предусмотрено восстановление сохранённых исходных значений.
