# SystemTunerPro

Windows-приложение для поиска и очистки временных файлов, управления внутренней корзиной, переноса файлов и настройки отдельных системных параметров.

## Возможности

- сканирование временных файлов, браузерных и приложенческих кэшей;
- выбор отдельных файлов и групп перед удалением;
- удаление в корзину или окончательное удаление через настройку безопасности;
- восстановление файлов из внутренней корзины;
- перенос файлов с сохранением структуры папок;
- импорт, экспорт и создание тем;
- управляемые твики Defender, Windows Update и параметров памяти с сохранением исходных значений.

Твики Windows требуют запуска от имени администратора. Перед применением системных изменений программа сохраняет исходные значения для восстановления.

## Сборка

```powershell
dotnet build -c Release
```

## Релизные варианты

Для создания двух portable-вариантов под Windows x64:

```powershell
.\scripts\publish-release.ps1 -Version 1.0.0
```

Скрипт создаёт небольшой одиночный `SystemTunerPro.exe`, которому нужен .NET 9 Desktop Runtime, и self-contained ZIP portable-версии со всеми DLL. Папка `release/` предназначена для локальных артефактов и не добавляется в Git.

Проект предназначен для Windows и использует .NET 9 и Avalonia UI.
